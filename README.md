# 🎥 Future Frame Prediction Using CNN-LSTM

A Flask-based Deep Learning project that predicts future image frames using a CNN-LSTM model built with TensorFlow and OpenCV.

## 📸 Project Preview

![Project Screenshot](screenshots/image.png)

---

## 🚀 Features

- Upload an input image
- Image preprocessing using OpenCV
- CNN-LSTM based future frame prediction
- Flask web interface
- TensorFlow/Keras model
- Displays predicted output frames

---

## 🛠️ Technologies Used

- Python
- TensorFlow

## ⚙️ Run the Project

```bash
git clone https://github.com/Vi9dprajapati/Future-Frame-Prediction-Using-CNN-LSTM.git

cd Future-Frame-Prediction-Using-CNN-LSTM

pip install -r requirements.txt

python app.py
```

Open in your browser:

```
http://127.0.0.1:5000
```

## ⚠️ Note

This project currently accepts a single image as input. The image is internally converted into a sequence before being passed to the CNN-LSTM model for future frame prediction.
